# 隐私与安全

文章和偏好默认保存在本机，不包含开发者遥测。网络图片会向其所在服务器发起请求；打开发布平台会加载该平台网页和依赖资源。登录数据由 WebKit 持久化管理，应用不导出 Cookie。

预览过滤脚本、iframe、事件属性和危险 URL，再生成高亮文本节点。过滤器是减少执行风险的措施，不是完整的安全审计。

隐私抹除对规则可识别的姓名、联系方式、路径用户名及 API/token/key 等凭据进行等长度星号替换。图片、模糊表达或规则未覆盖的格式需要人工检查。测试夹具使用演示信息和虚构凭据，不应替换成真实账号数据。

请勿将 `articles.json`、浏览器数据、Cookie、私有 Markdown、真实密钥、签名证书或本地调试输出提交到 GitHub。仓库 `.gitignore` 默认排除历史产物和工作目录。
